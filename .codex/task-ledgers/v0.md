# Every Park v0

## Goal and success
Ship a mobile-first Vancouver Island park and island collecting app to NathanPannell/every-park using Next.js/Vercel, FastAPI/Railway, and Neon. Success requires reliable attributed seed data, clustered interactive game-style map, persistent personal checkoffs, meaningful automated checks, independent review, deployed mobile/desktop browser verification, and production URL delivery.

## Scope and assumptions
- National, provincial, regional parks on Vancouver Island; nearby Gulf/Discovery major islands included as a curated category.
- Anonymous personal collections for v0; no signup. Explicit data coverage and source links; representative pins are not navigation/trailhead claims.
- User authorized clone, push, provisioning, deployment and browser use without extra feedback.
