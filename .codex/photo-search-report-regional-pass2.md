# Regional photo pass 2

Completed 2026-09-11. Scope: the 34 regional parks still lacking photos after the catalogue pass. Every park had already received exact-name and shortened-name Wikimedia Commons searches plus an Openverse commercial-license search. This follow-up checked documented features/aliases, direct Flickr results, Commons categories, and/or coordinate candidates where the sources exposed them. Candidates were accepted only when both exact-place evidence and a file-level commercial redistribution license were verified.

## Result

- Verified and downloaded: **2** (Brooks Point, Stoney Hill).
- Rejected or still unverified: **32**.
- Commons coordinate searches attempted before shared API throttling: **17**. The batch was stopped to avoid interfering with the provincial photo worker; an API throttle is not treated as an empty result.
- No product files or shared manifests were changed.

## Limits

This is a bounded source pass, not proof that no reusable photo exists anywhere. Search-engine indexing, Commons throttling, and missing file-level license metadata limited some routes. The withheld files must remain missing unless a later review establishes both exact park placement and a compatible per-file license; captions alone do not establish reuse rights, and broad geographic proximity does not establish a park match.
