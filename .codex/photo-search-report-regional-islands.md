# Regional park and island photo search report

Search completed 2026-09-11 against Wikimedia Commons first, followed by an Openverse commercial-license query for residual gaps. All 77 missing regional/island places were searched. The integrated candidates were independently rechecked against current landing-page metadata and visually inspected before local variants were created.
