## Future hourly authoring run, currently inactive

After the rank 1 reconciliation passes and the operator sets up the heartbeat, each run invokes one queue claim. That command leases at most one eligible ranked job, returns a token and park details, and exits. There is no catch-up loop, held database transaction during research, or always-on worker. A failed job may be retried at most three times; a job needing human attention is skipped so later parks can continue in subsequent hours. The table below describes the queue command surface for the future runs.

The task-owned `run-authoring.py` wrapper binds each command to staging or the owned PR 18 preview and loads credentials from the operator's private configuration. Its global arguments are `--target`, `--expected-database-host`, and, for preview, the explicit `--preview-journal` and `--preview-credential-file`. All commands return machine-readable JSON. The operator sequence is:

| Step | Wrapper operation or queue command | Required evidence or result |
| --- | --- | --- |
| Inspect | `queue status` or `queue status --rank N` | Counts, state, attempt number and spent render calls. |
| Lease once | `queue claim` | One rank, lease token and deterministic work directory, or a busy/completed result. |
| Save research | Write the dossier JSON and source images in the task-owned directory, then `queue freeze --rank N --lease-token TOKEN --research-json PATH` | At least five distinct researched Google image files, fact URLs and dossier hash are frozen before generation. |
| Record each call | Write the immutable `render-call-01.json` through `render-call-05.json` manifest, then `queue start-render --rank N --lease-token TOKEN --run-manifest PATH` | Invoke image generation only when the result is `checkpointed`. `already_checkpointed` means that call is spent, even if its output is unknown. |
| Choose art | `queue select-art --rank N --lease-token TOKEN --selected-art-json PATH` | Three initial compositions have been recorded, gallery comparison is complete, and the chosen WebP hash plus expected/current Park fields are frozen. |
| Publish | `queue publish --rank N --lease-token TOKEN` | The selected R2 object and Park update are verified, then the queue records `published`. The wrapper supplies Cloudflare identity internally. |
| Recover | `queue renew`, `queue fail`, or `queue recover` with the rank/token flags shown by `--help` | Preserve the recorded calls and frozen inputs. On the third failed attempt the job needs attention; a later hourly run may claim another rank. |
